# Security Policy

ESP32 SecureCheck is a local static-analysis utility. It does not connect to devices, exploit systems, or upload scanned source code.

Do not publish exploitable details in a public issue. Contact the repository maintainer privately through the GitHub profile and include the affected version, reproduction steps, expected and actual behavior, and potential impact. Never include real credentials or private data.

A clean scan is not a security certification. Findings are heuristic and require human review.
